# Personajes realistas de empleados

Modelos GLB generados con Ara 3D Gen (https://ara3dgen.com/), con la animación «Sit idle (chair)». El código de Ara es MIT; los datos de los personajes de MakeHuman son CC0. Según la documentación del proyecto, las exportaciones se pueden usar en proyectos comerciales y no comerciales.

La captura de movimiento procede de la CMU Graphics Lab Motion Capture Database: https://mocap.cs.cmu.edu/. Datos obtenidos de mocap.cs.cmu.edu; base de datos creada con financiación NSF EIA-0196217. El proyecto indica que se pueden utilizar en productos comerciales, pero no revender los datos de captura por separado.

Fuentes: https://github.com/olatunde85/3d-gen#licensing y https://ara3dgen.com/docs/exporting/.
